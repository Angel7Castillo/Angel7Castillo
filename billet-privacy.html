Política de Privacidad — Billet Desktop Pro

Última actualización: 15 de noviembre de 2026
Aplicación: Billet Desktop Pro (TechService.BilletDesktopPro)
Editor / Publicador: Tech Service

1. Arquitectura 100% Local (Offline-First) y Cero Recolección de Datos

Billet Desktop Pro es una estación de gestión financiera y contable para Windows (Modo Personal y Modo Empresa / PyME) que opera de manera estrictamente local en el dispositivo del usuario.

  • No recopilamos información personal: La aplicación no recopila, no almacena en servidores externos, no transmite, no vende ni comparte datos personales, financieros, bancarios ni contables con Tech Service ni con terceros.
  • Almacenamiento local exclusivo: Todos los libros contables, cuentas de tesorería, asientos del Libro Diario, terceros (clientes y proveedores), obligaciones y arqueos de caja permanecen guardados únicamente en el almacenamiento local del equipo del usuario.

2. Uso de Permisos del Sistema (Windows Desktop / runFullTrust)

El paquete oficial .msix distribuido a través de Microsoft Store utiliza el motor nativo Tauri v2 (Rust + Microsoft Edge WebView2). Los permisos de escritorio se utilizan exclusivamente para ejecutar la interfaz nativa, persistir la base de datos financiera en el equipo del usuario y permitir la exportación manual de reportes contables en formato CSV al disco local.

3. Control del Usuario y Eliminación de Datos

El usuario posee control absoluto sobre sus registros en todo momento. Puede editar, exportar a CSV o eliminar cualquier libro contable o movimiento desde la propia aplicación. Al desinstalar la aplicación de Windows, todos los datos locales asociados pueden ser eliminados permanentemente del dispositivo.
